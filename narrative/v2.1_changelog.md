# v2.1 changelog

mostly cleanup after the bigger v2 work.

## package / imports

Added proper package files:

- app/__init__.py
- processors/__init__.py

Main imports should now work from repo root.

Did a scan for weird paths and old typo style imports.

No more app workflow import like:

app.payroll_review_workflow

That got moved.

## workflow spine

Moved the main product flow into:

processors/payroll_review_workflow.py

This is now the main thing:

run_payroll_review(current_file, previous_file, variance_threshold)

It now does the full chain:

1. save uploaded files temporarily
2. extract current payroll
3. extract previous payroll
4. reconcile
5. detect anomalies
6. build the review pack
7. return one result object

The result now includes:

- current extraction
- previous extraction
- reconciliation dataframe
- anomalies dataframe
- summary
- variance threshold
- review workbook bytes

So the dashboard does not need to know how to build the workbook anymore.

## report generator

Added:

processors/report_generator.py

This is the cleaner public entry point now.

It points into the modular v1 report generator folder.

Changed report generation so it takes the review result object:

generate_review_workbook(result)

instead of passing loads of separate pieces around.

Cleaner enough for now.

## dashboard

Updated Streamlit bits to call the new workflow.

The download button now just uses:

result.review_workbook_bytes

No extra dashboard workbook function.

Removed the old app-side workflow file:

app/payroll_review_workflow.py

## tests

Updated tests for the new flow.

Added a workflow test that checks:

- current extraction exists
- previous extraction exists
- reconciliation exists
- summary exists
- workbook bytes look like an xlsx
